# Compact BTC risk circuit feasibility spike

This spike checks whether the SILENCE TypeScript risk calculator's core fixed-lot BTC arithmetic can be expressed and simulated in Compact 0.31.1. Amount fixture values are normalized by 1,000,000 from `src/risk/calculator.ts`; both entry and mark prices are scaled by the same factor relative to the reference, so P90/P84 and payout results preserve its ratios and integer rounding outcomes. The prices are fixtures, not a real or authenticated BTC quote.

The circuit covers one isolated position with fixed collateral `1000`, maximum notional `5000`, a `500` bps maintenance margin, user supplied bounded fees / exit cost / protective buffer, and a maximum `500` profit payout per slot. It rejects zero prices and out-of-range inputs, computes loss PnL with conservative ceiling magnitude, computes current notional and maintenance with ceiling division, decides protective close versus liquidation, and caps payout.

Compact 0.31.1 does not parse `/` as an integer division operator. The circuit therefore gets quotient and remainder from a local witness callback and proves `q * denominator + remainder == numerator` plus `remainder < denominator` inside the circuit. A deliberately incorrect callback is tested and rejected. Witnesses cannot select a different quotient that passes those checks.

`blockTimeGte` and `blockTimeLt` compile in the pinned compiler and are simulated against the runtime's controlled block-time input. A quote exactly `maxAgeSeconds` old is accepted; the next older second and future timestamps reject. The timestamp horizon is bounded to 4,000,000,000 seconds and max age to one day to make the freshness-bound addition overflow-safe. A separate predicate accepts only a sequence greater than the previously accepted sequence; that previous value is a caller input in this spike, not authenticated or anchored ledger state.

## Run

From this directory, run `npm test`. Dependencies resolve from the parent project installation. The compiler script uses the project `.tools/compact` installer if present, or `COMPACTC` / `compact` from `PATH`. Local development used the already-installed Compact 0.31.1 binary from the preserved sibling BlindAid checkout; that binary is not part of this repository. For a clean clone, install the root project's pinned compiler with `npm run setup:compiler` first.

Generated compiler output is ignored by Git. The compiler emits `.zkir`, `.bzkir`, and prover/verifier key files for this circuit; tests invoke its generated TypeScript simulator and do not construct a transaction proof. The circuit does not deploy, read or authenticate a real oracle, transfer collateral, or validate perp settlement. The mark, quote timestamp, and previous sequence are supplied as call inputs, so production must authenticate the oracle source and anchor accepted sequence state before treating either freshness or anti-replay checks as meaningful. Every `RiskResult` field is explicitly disclosed because the isolated harness returns exact arithmetic outputs for fixture comparison. Do not reuse this output shape as an on-chain production circuit while claiming position confidentiality.
