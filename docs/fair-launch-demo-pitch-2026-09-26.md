# Fair Launch — 3분 데모 피칭 동선

상태: 촬영용 초안. Local Devnet 테스트 자산만 사용한다. 실제 브라우저 봉인 입찰·청구는 아직 지원하지 않으므로 영상에서 버튼이 작동하는 것처럼 연출하지 않는다.

| 시간 | 화면/행동 | 말할 핵심 |
|---|---|---|
| 0:00–0:20 | Explore와 Create 버튼 | “밈코인 출시 첫 순간에는 먼저 보거나 먼저 들어간 사람이 유리합니다. Fair Launch는 출시를 봉인 입찰의 한 구간으로 시작합니다.” |
| 0:20–0:55 | Create의 토큰 정보·재고·최저가 입력과 미리보기. Local Devnet 운영자 데모 모드에서 `Create test launch` 실행 또는 이미 확인된 `Night Bloom Test` 카드/영수증 표시 | “사용자가 토큰과 경매 규칙을 정합니다. 지금 시연은 Local Devnet의 운영자 테스트 지갑이 배포·1회 발행·재고 예치를 서명하는 MVP입니다. 세 거래가 확정돼야 Explore에 나타납니다.” |

| 1:15–2:00 | 원래 정산된 토큰 상세의 네 슬롯 결과 | “이 경매에서는 네 명이 같은 공개 예치액을 넣고 최대가격·희망량을 봉인했습니다. 판매량 600개를 청산가 10에 배정해 두 명이 300개씩 받고, 나머지 두 명은 전액 환불받았습니다. 낙찰자도 미사용액을 돌려받습니다.” |

| 2:35–3:00 | 공개 범위·한계 한 장 | “Compact는 봉인값과 모든 등록 입찰의 정산 규칙을 증명합니다. 청산가·슬롯별 배정과 환불은 공개됩니다. 지금은 4인 Local Devnet 데모이며, 브라우저 지갑 입찰·본딩커브와 원시 거래 프라이버시 감사는 다음 단계입니다.” |

## 녹화 시 확인할 것

- `Night Bloom Test`와 `Midnight Moth Test`의 **발행·예치 3건씩**은 [검증된 카탈로그](../web/fair-launch-catalog.json), 원래 4인 경매의 **20건**은 [별도 증거](../spikes/fair-launch/docs/evidence/local-devnet-fair-launch.json)다. 새 토큰 두 개가 이미 정산된 것처럼 섞어 말하지 않는다.
- 공개 정적 사이트에서 Create의 미리보기는 가능하지만 실제 발행은 로컬 운영자 데모 서버가 켜진 경우에만 가능하다. 공개 URL에 그 서버가 연결되지 않았다면 영상에서 로컬 데모라고 표시한다.
- 화면에 등장하는 테스트 자산은 가치가 없고, `Graduated`, 시가총액, 현재 시장가격, 수익률을 보여주지 않는다.

## 제출용 한 문장

“Fair Launch는 Midnight Compact로 봉인된 초기 매수 입찰을 한 가격에 검증·배정하고, 테스트 토큰의 발행부터 환불·청구까지 실제 Local Devnet에서 실행한 밈코인 출시 MVP입니다.”
