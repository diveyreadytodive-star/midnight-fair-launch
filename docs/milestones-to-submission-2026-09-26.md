## 우선순위와 명칭 판정

1. **기능보다 먼저 M1 푸시.** 현재 GitHub 저장소는 비어 있다. 대회가 저장소를 clone·compile하고 README/폼 일치와 데모 접근성을 확인하므로, 공개 재현 가능한 체크포인트가 우선이다.
2. **M2가 정산의 Go/No-Go.** 실제 LP 지급이 실패하면 시간을 더 쓰더라도 `perp DEX`라고 제출하지 않는다. M3를 중단하고 G2에서 입증한 비공개 위험 종료·후속 청구를 정확히 시연한다.
3. **M3 통과 전에는 주문 버튼 비활성 유지.** 현재 브라우저 지갑은 읽기 전용이며, 서버 위험 엔진은 순수 상태기계일 뿐 실제 체인 adapter가 아니다.
4. **프라이버시 약속은 활성 포지션으로 한정.** 고정 담보·가격·종료 시각은 공개되고, 종료 뒤 방향이 추론된다. 운영자는 포지션 원문을 본다. 이것이 시장에 나갈 수 있는 신뢰 경계인지 사용자 검증은 아직 없다.
5. **대회 제출 이름과 주장:** 이름은 SILENCE를 유지하되, M3 실패 시 부제는 `Private Perp Risk Primitive` 또는 동등한 정확한 표현으로 바꾸고 DEX 기능 목록을 줄인다. M3와 M4를 모두 통과해야만 `작동하는 비공개 perp DEX 프로토타입`이라고 쓸 수 있다. 실거래·상용 안전성은 어느 경우에도 주장하지 않는다.
